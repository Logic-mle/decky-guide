## Decky Guide 1.0.0 · 首个正式版

在 Steam Deck 游戏模式中自动识别当前游戏，搜索游民星空攻略，并在 Decky 侧栏直接阅读图文内容。

### 主要功能

- 自动匹配中文游戏名称，支持手动搜索并按游戏记住别名。
- 图文阅读、章节目录与关键词筛选、上一页 / 下一页和原文入口。
- 按游戏保存阅读进度，支持继续阅读、三档字号和图片放大至 200%。
- LB / RB 按住滚动，X 打开目录，Y 打开阅读设置，B 分层返回。

### 安装

1. Steam Deck 需先安装 [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader#installation)。本项目以 3.2.8 接口为基准，其他版本兼容性需实机确认。
2. 在本页 Assets 下载 **DeckyGuide-v1.0.0.zip**，无需解压或编译。
3. 在 Decky 设置中启用开发者模式，使用从 ZIP 安装；若界面提供从 URL 安装，可使用下方直链。
4. 安装完成后打开 Decky Guide，启动游戏或手动输入中文游戏名搜索。

[下载安装 ZIP](https://github.com/Logic-mle/decky-guide/releases/download/v1.0.0/DeckyGuide-v1.0.0.zip)

GitHub 自动生成的 Source code 压缩包不含编译产物，不能作为插件安装包。`.zip.sha256` 用于校验下载完整性，不需要安装。

### 从测试版升级

这是基于 0.6.5 功能整理的首个正式开源版本，补齐文档、版本和发布流程。直接覆盖安装；本地存储键保持一致，保留 Steam UI 本地存储时无需迁移。清理本地存储会删除记录。

### 验证与已知限制

发布流程自动执行类型检查、5 项阅读状态测试和构建，并校验 ZIP 内容。未在本次发布流程中执行 Steam Deck 实机兼容性测试；浏览器模拟不能替代原生手柄焦点验证。

需要联网，游民星空页面变化可能影响搜索或解析；重名及非 Steam 游戏可能需要手动匹配。视频、互动地图与脚本内容可能需打开原文查看。阅读进度不跨设备同步。
